# Feature Inventory Matrix — Wex Technology (Storefront & Admin)

**Document Version:** 1.0.0  
**Updated:** 2026-11-25  
**Surfaces Covered:** Storefront (React PWA), Admin Panel (React PWA), Backend API (CodeIgniter 4)  
**Priority Classification:**  
- **P0**: Core customer shopping journey, order lifecycle, payments verification, price lock, and settings/content synchronization that impacts customer visibility and store operations.  
- **P1**: Secondary administrative actions, static content views, comparisons, wishlist, user preferences, and audit trails.
