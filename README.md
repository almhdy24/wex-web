# متجر ولوحة تحكم ويكس تكنولوجي (Wex Technology Web)

تطبيق ويب حديث ومتكامل للتجارة الإلكترونية مع دعم تطبيق الويب التقدمي (PWA) ولوحة تحكم إدارية احترافية لمتجر **ويكس تكنولوجي (Wex Technology)**، المتخصص في بيع أجهزة اللابتوب والهواتف الذكية والإلكترونيات في أم درمان، السودان.

تم بناء هذا المشروع كواجهة أمامية مستقلة في `~/projects/wex-web` تتكامل مع واجهة RESTful API الخلفية الموجودة في `~/projects/wex-api`.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. واجهة المتجر العامة للعملاء (Public Storefront):
- **تصميم عربي أولاً (Arabic-First RTL):** مبني بالكامل ليلائم متطلبات السوق والمستخدم السوداني باستخدام خط **Tajawal** وألوان الهوية الرسمية (الكحلي الملكي، الأزرق، والأزرق الجليدي، مع لمسات محسوبة من السماوي).
- **كتالوج أجهزة متقدم:** تصفح وتصفية فورية حسب نوع الجهاز (لابتوب، هاتف، ملحقات)، الماركة، الحالة (جديد، كرتونة مفتوحة، مستعمل، مجدد)، ونطاقات السعر.
- **صفحة تفاصيل الجهاز:** معرض صور تفاعلي، جدول مواصفات فنية منظم، نص الضمان المعتمد، وقسم ملحقات مقترحة مرتبطة بالجهاز.
- **سعر الصرف النبضي اللحظي:** احتساب الأسعار فورياً بالجنيه السوداني بناءً على سعر الصرف اليومي للدرهم الإماراتي مع شريحة توضيحية أعلى الصفحة.
- **سلة شراء ذكية:** تخزين محلي تلقائي، تقييد للكمية حسب المخزون الفعلي، وسقف أقصى 10 قطع لكل منتج لمنع حجز البضائع.
- **إتمام الطلب الميسر:** خيار الاستلام من مقر المحل بأم درمان (مجاناً) أو التوصيل لكافة ولايات السودان مع احتساب رسوم التوصيل تلقائياً.

### 2. عمليات وحسابات العملاء (Customer Operations):
- **تسجيل دخول بدون كلمة مرور (Passwordless Email OTP):** طلب رمز تحقق مكون من 6 أرقام يصل لبريد العميل، مع مؤقت عد تنازلي (60 ثانية) وإمكانية إعادة الإرسال.
- **دعم الدخول عبر Google:** تكامل سلس مع Google Identity Services (GIS).
- **تثبيت سعر الصرف لمدة 4 ساعات:** شريط عد تنازلي حي في صفحة الطلب يحمي العميل من تقلبات سعر الصرف أثناء تحويل المبلغ عبر تطبيق بنكك.
- **بطاقة تحويل بنكك (Bankak):** عرض بيانات الحساب البنكي وزر نسخ مباشر لرقم الحساب لتسهيل التحويل بدون أخطاء.
- **رفع إشعار التحويل المالي:** نافذة مخصصة لرفع صورة إشعار بنكك مع اسم المحول ورقم العملية وتحديث فوري لحالة الطلب.
- **مركز التنبيهات المدمج:** إشعارات فورية بحالات الطلب وقبول الدفع، مع عداد إشعارات غير مقروءة في الهيدر.

### 3. لوحة التحكم والإدارة (Administration Dashboard):
- **لوحة معلومات تشغيلية (Operational Dashboard):** إحصائيات المبيعات، الطلبات اليومية، تنبيهات إشعارات الدفع المعلقة للمراجعة، وتنبيهات الأجهزة ذات المخزون المنخفض.
- **إدارة دورة حياة الطلبات (Order State Machine):** تحديث الحالات بدقة (`confirmed`, `ready_for_pickup`, `out_for_delivery`, `completed`, `cancelled`) مع تسجيل اسم وهاتف مندوب التوصيل وتمديد مهلة تثبيت السعر عند الحاجة.
- **مراجعة إشعارات الدفع:** عرض صورة الإشعار البنكي الأصلية، اعتماد الدفع بنقرة واحدة، أو الرفض مع تدوين سبب الرفض.
- **إدارة كتالوج المنتجات:** إضافة وتعديل الأجهزة، منشئ المواصفات الفنية بالقوالب الجاهزة للابتوبات والهواتف، إدارة ورفع الصور المتعددة وتحديد الصورة الرئيسية، وتعديل سريع للمخزون.
- **إدارة الفئات والماركات:** تحكم كامل في تصنيفات الأجهزة والشركات المصنعة.
- **إدارة سعر الصرف:** تعديل سعر صرف الدرهم مقابل الجنيه السوداني مع شاشة تأكيد تحذيرية وسجل تاريخي للتعديلات ومسؤوليها.
- **إعدادات المتجر ومناطق التوصيل:** تعديل بيانات المحل، حساب بنكك، ساعات القفل، ورسوم التوصيل لولايات السودان.
- **إدارة المستخدمين وسجل العمليات:** استعراض العملاء، تعديل الصلاحيات (`customer`, `staff`, `admin`) مع حماية لمنع المدير من خفض صلاحياته بنفسه، وسجل تدقيق شامل (Audit Trail).

### 4. تطبيق ويب تقدمي (PWA & Offline Support):
- **تثبيت التطبيق:** إمكانية تثبيت المتجر كتطبيق مستقل على هواتف أندرويد وiOS.
- **كشف انقطاع الإنترنت:** شريط تحذيري عند فقدان الاتصال بالشبكة مع توجيه ذكي لصفحة العمل بدون إنترنت (`/offline`).
- **تخزين مؤقت آمن:** عزل أمني صارم يمنع حفظ أي بيانات خاصة بالطلبات أو التوثيق في الكاش.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **React 19:** لبناء الواجهات التفاعلية الحديثة.
- **Vite 8:** لتجميع وبناء الحزم بأعلى أداء وسرعة.
- **React Router 7:** لإدارة التنقل والحراسة الأمنية للمسارات.
- **Context API:** لإدارة الحالات المشتركة (المصادقة، السلة، التنبيهات).
- **CSS Tokens & Native CSS:** تصميم خفيف ومرن بدون أطر ثقيلة لضمان السرعة على الأجهزة الضعيفة (4GB RAM).
- **vite-plugin-pwa:** لتوليد Service Worker وإدارة ملف البيان (Manifest).
- **Vitest:** لإجراء اختبارات الوحدة السريعة.

## 🚀 البدء والتشغيل (Getting Started)

### المتطلبات المسبقة:
- Node.js (الإصدار 18 أو أحدث).
- تشغيل خادم الواجهة الخلفية `~/projects/wex-api` على المنفذ `8081`.

### 1. إعداد متغيرات البيئة:
انسخ ملف الإعداد النموذجي:
```bash
cp .env.example .env
```

محتوى الملف:
```env
VITE_API_BASE_URL=http://localhost:8081/api/v1
VITE_GOOGLE_CLIENT_ID=
VITE_APP_NAME="Wex Technology | ويكس تكنولوجي"
```

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. تشغيل وضع التطوير:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:5173`

### 4. تشغيل الاختبارات الآلية:
```bash
npm run test
```

### 5. بناء حزمة الإنتاج:
```bash
npm run build
```

## 🛡 الأمان والموثوقية (Security)
- لا يتم تمرير أي رموز سرية أو OTP في عناوين URL أو طباعتها في سجلات الكونسول.
- يتم تخزين رمز الوصول في الذاكرة الحية لمنع استخراجه بواسطة برمجيات خبيثة.
- واجهة برمجة التطبيقات الخلفية هي السلطة الوحيدة للتحقق من الأذونات وتغيير حالات الطلبات والدفع.
